# 开发路线图

0.4 已把参考节点目录的主要空缺推进到可执行子集：层级组件、多通道采样、网格/材质/场景、GLSL、Python、开放协议与设备桥接。实际范围以 [功能矩阵](FEATURE_MATRIX.md) 和 [逐项清单](reference-capabilities.json) 为准；不存在完整 TouchDesigner 等价声明。

接下来的开发按实际能力验收：

1. **原生设备驱动**：为 92 个外部入口逐组实现独立适配器，先明确目标平台、SDK 许可、硬件与测试场景；使用真实设备完成收发、断连重连和资源释放测试。桥接接口通并不等于驱动已交付。
2. **实时计算与精度**：统一 GPU 纹理/缓冲区、浮点/HDR、线性色彩、脏标记调度、节点耗时与资源预算；公布硬件、分辨率、帧时间和长期运行记录。
3. **3D 与动画深度**：完善退化网格、属性传播、曲线/拓扑质量、模型动画、材质参数、完整时间线和可复用组件的公开参数/版本管理。
4. **音视频与演出**：固定采样时钟、专业音频驱动、音画封装、确定性离线导出、编码选项、多屏与帧同步、投影校正/边缘融合。
5. **AI 长任务**：持久队列、轮询、取消、重试、产物归档、成本记录；每种模态至少验证一个真实供应商，并保留模型与提示词元数据。
6. **MCP 与扩展**：长期会话、OAuth、资源/提示、订阅与更明确的工具权限；稳定插件 API、schema 迁移、安装器、跨平台设备权限与无障碍检查。

现有 Python Script 按受信任本机代码执行，不是多租户沙箱。面向公网部署前需单独实现认证、隔离、访问控制与配额，不能仅改变监听地址。

对照商业软件文件格式、API 和 GPU 行为需要独立设计与验证，节点同名和截图外观都不能作为验收标准。
