# 功能矩阵与兼容边界

更新日期：2026-10-13。本文记录 TD Open 的早期实现范围，不是 TouchDesigner 全功能复刻完成声明。节点同名仅表示创作概念相近，不能推断参数、数据结构、画面结果、项目格式或性能兼容。

状态含义：**基础**表示有对应实现但只覆盖表中子集；**接入**表示提供真实请求或协议入口，结果依赖外部服务；**计划**表示尚未实现。测试通过范围另见实际测试结果，不能从“基础”推断已经在所有操作系统、显卡或第三方服务上验证。

## 编辑器、项目和学习体验

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| 节点网络编辑 | 基础 | React Flow 画布、节点位置、连线；当前图计算按有向无环图设计 |
| 自由工作台 | 基础 | 节点库、预览、节点画布、参数与助手五个独立面板，可拖动、四边/四角缩放、隐藏、置顶与最大化；布局随项目保存 |
| 节点库与搜索 | 基础 | 99 个内置节点（TOP 50 / CHOP 24 / SOP 11 / DAT 8 / AI 5 / OUT 1），中文/英文/类型 ID 搜索与分族说明；完整清单见 [节点手册](NODES.md)；不是原软件完整算子目录 |
| 参数面板 | 基础 | 数值、颜色、布尔、枚举和文本参数；不具备完整参数表达式语言 |
| 类型化输入输出 | 基础 | 画面、信号、几何、文本分型，检查不兼容连接；不支持任意隐式转换 |
| 实时预览与播放控制 | 基础 | 浏览器内逐帧预览；不能据此保证固定帧率或硬件同步 |
| 示例工程 | 基础 | 八个预设（含空白工程），包括万花筒反馈、双几何体合并、CSV 驱动画面；也提供八份可导入 JSON 文件 |
| 项目存储 | 基础 | 本地 Python 服务与 JSON 项目；不是 `.toe` / `.tox` 格式 |
| 撤销、重做与自动保存 | 基础 | 编辑历史与本地自动保存；不支持多人合并和文件修订管理 |
| 图修改 API | 基础 | 通过经过校验的命令修改图；操作范围取决于命令白名单 |
| 项目层级与复用组件 | 计划 | 无 COMP 子网络、组件公开参数、克隆、相对 operator path 等完整模型 |
| 完整时间线与关键帧 | 计划 | 当前时间驱动动画不等于关键帧编辑器、动画曲线或 cue 系统 |
| 多人协作与版本合并 | 计划 | 无多用户并发编辑、冲突合并、账户和团队权限 |
| 交互式课程与无障碍审计 | 计划 | 现有说明和模板是基础；系统课程、键盘操作与读屏验证仍需完善 |

## 图像、视频与 TOP 类能力

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| 程序化纹理 | 基础 | `noise` 在 GPU 以 320 × 180 生成并缩放进入 640 × 360 管线；不与 Noise TOP 数值兼容 |
| 渐变与形状 | 基础 | `ramp`、`shape`，新增纯色、棋盘格、网格、条纹、椭圆、圆角矩形、多边形、星形、径向渐变、圆环与波浪线 |
| 图片/视频素材 | 基础 | `media` 使用浏览器可读取的素材；格式能力受浏览器解码器和资源跨域策略约束 |
| 色彩调整 | 基础 | `color` 加反相、黑白、阈值、色阶分段、伽马、对比度、黑白场；无完整专业色彩管理 |
| 模糊与柔光 | 基础 | `blur`；基于当前渲染实现，不是完整多阶段 bloom 管线 |
| 2D 变换 | 基础 | `transform` 加裁剪、画幅适配、翻转、镜像、万花筒、平铺、连续旋转与纹理位移 |
| 图层合成 | 基础 | `composite` 加亮度/透明度遮罩、色度抠像、画面切换、差值与色差分离 |
| 文字画面 | 基础 | `text` 生成文字图像；不是 DAT 表格/脚本系统 |
| 输出节点 | 基础 | `output` 选择最终画面；不是 Window COMP 的原生多屏输出 |
| 基础像素分析 | 基础 | Sobel 边缘、差值比较、锐化、浮雕；不包含稠密光流或语义分割模型 |
| 光流与语义背景分离 | 计划 | 未实现对应分析算子或专用 GPU 模型 |
| 显式图像反馈 | 基础 | `feedback` 保存自身上一帧并执行缩放、旋转、衰减和叠加；无需建立循环连接 |
| 一般循环、图像缓存与延迟 | 计划 | 当前仍禁止一般图循环；无任意帧数缓存与时间寻址网络 |
| 自定义 GLSL / WGSL | 计划 | 内部使用着色器不等于向用户开放着色器节点 |
| 浮点/HDR/多平面/3D 纹理 | 计划 | 当前不提供与专业纹理网络相同的格式与精度控制 |
| 专业视频文件 I/O | 计划 | 无 FFmpeg 工作流、统一编解码选项、硬件解码保证和帧精确寻址 |
| PNG 与 WebM 画面导出 | 基础 | 浏览器画布导出到 `data/exports/`；WebM 实时录制不含音轨，实际帧率受运行性能影响 |
| 离线逐帧渲染 | 计划 | 尚无确定性帧序列渲染、音画封装和专业编码配置 |
| 摄像头与采集卡 | 计划 | 麦克风接入不代表视频设备支持；原生采集卡需要独立桥接 |

## 信号、音频与 CHOP 类能力

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| 常量与低频波形 | 基础 | `constant`、`lfo` 加时间、BPM 节拍、锯齿波、方波、三角波和固定种子随机信号；没有完整命名通道/采样时间片模型 |
| 数值运算 | 基础 | `math` 加范围映射、限幅/循环/镜像、逻辑比较、正弦、绝对值、步进量化与信号切换 |
| 参数调制 | 基础 | 指定 `mod` 端口驱动部分节点；没有任意参数绑定与 CHOP Export 兼容性 |
| 麦克风输入 | 基础 | 浏览器权限授权后的音量/频谱；通常要求 localhost 或 HTTPS 安全上下文 |
| 本地音频文件 | 基础 | 上传与保存资源引用、手动播放、音量/频谱驱动；当前仅共享一路活动音源 |
| 频谱画面 | 基础 | `spectrum` 将音频数据可视化；不是完整多通道信号频谱网络 |
| 音频播放/生成资产 | 接入 | 生成服务可返回音乐资源；完整采样器、音频时间线和混音仍需建设 |
| 多通道采样与时间片 | 计划 | 无完整 CHOP 样本范围、采样率协商、时序重采样和音频时钟模型 |
| 有状态信号处理 | 基础 | 浏览器逐帧运行滞后平滑、积分、微分、脉冲计数、触发包络和采样保持；回退时间或修改参数时重置历史 |
| 音频节拍检测、音高与专业滤波 | 计划 | BPM 节拍发生器不等于从音频分析节拍；未覆盖专用音频分析算子库 |
| 专业音频 I/O | 计划 | 未接入 ASIO、CoreAudio 多通道、低延迟回调和音频设备路由 |
| MIDI、OSC、DMX 信号 | 计划 | 需要协议适配器；不能因图中存在信号端口而认为设备已支持 |

## 3D、SOP / POP / MAT 与组件

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| 基本几何体 | 基础 | `geometry` 加独立立方体、球体、圆环、圆锥、圆柱、平面、圆面与空间线段，均可接到 `render` |
| 三维渲染 | 基础 | Three.js / WebGL、基础灯光、颜色、线框和旋转；不具备完整 Render TOP 功能 |
| 粒子视觉 | 基础 | `particles` 是粒子风格的画面生成节点；不代表 POP GPU 点属性系统 |
| 几何变换与合并 | 基础 | `transform_sop` 支持 XYZ 位移/旋转/缩放；`merge_sop` 合并场景组并保留各自变换，可串联与嵌套 |
| 网格编辑与几何处理 | 计划 | 场景组合并不焊接顶点；无完整 SOP 拓扑编辑、布尔、细分、变形、曲面和属性算子 |
| POP 点/顶点/图元属性 | 计划 | 无 GPU 点网络、属性缓冲区、compute 算子及其跨族转换 |
| 实例化、骨骼与动画 | 计划 | 无完整实例属性、蒙皮、骨骼动画或动画文件导入 |
| 独立材质网络 | 计划 | `render` 的颜色/线框参数不是 MAT 算子族；PBR 材质图与自定义材质仍待开发 |
| 相机/灯光对象网络 | 计划 | 当前渲染器内部相机和光源不等于可编辑的 COMP 场景层级 |
| 模型资源导入 | 基础 | `ai_3d` 结果 URL 可通过 GLTFLoader 读取 glTF/GLB；不支持任意 OBJ/FBX，外部资源和 CORS 需可访问 |
| 物理、流体与体积 | 计划 | 未实现原生物理模拟、碰撞、体积数据或 GPU 流体引擎 |
| 嵌套组件与面板控件 | 计划 | 未实现 COMP 子图、嵌套控制面板、组件事件与布局系统 |

## 文本、数据、脚本和开发扩展

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| AI 文本与工具结果 | 接入 | 文本生成和 JSON 工具结果；不是完整 DAT 算子网络 |
| 文本/JSON/CSV 数据算子 | 基础 | 8 个 DAT 节点覆盖文本、拼接、字面替换、大小写/反转、拆分、JSON 路径、CSV 单元格/JSON 输出与文本转信号；支持带引号及换行的 CSV；无独立电子表格编辑器 |
| Python 后端二次开发 | 基础 | Python 服务与节点注册接口，示例信号算子；需按模块注册与运行路径接入 |
| 任意 Python 脚本节点 | 计划 | 没有对用户脚本开放不受限 `eval` / `exec` 工作流 |
| 本地 Python 插件发现 | 基础 | 启动时扫描 `backend/plugins/` 并导入注册；仅服务端求值，不会自动出现在前端实时图中 |
| 插件热加载/市场 | 计划 | 无稳定插件 ABI、在线安装、隔离运行和前端自动扩展机制 |
| C++ / Rust 原生扩展 | 计划 | 未定义原生扩展 ABI 与 GPU 资源共享协议 |
| TouchDesigner Python API | 计划 | 没有 `op()`、`me`、原软件类层级与回调行为兼容承诺 |

## AI 服务与对话编辑

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| 服务商配置 | 接入 | 保存服务地址、模型与密钥，前端显示脱敏状态；密钥文件位于项目本地私有数据目录 |
| OpenAI 兼容文本 | 接入 | `/chat/completions` 请求；各服务商的模型、参数和错误格式需实际验证 |
| OpenAI 兼容图像 | 接入 | `/images/generations` 请求；不表示支持所有图像编辑或流式接口 |
| 通用 HTTP 生成服务 | 接入 | 自定义 endpoint、JSON 请求模板与响应归一化，可用于文本/图像/音乐/3D 服务 |
| 音乐和 3D 生成 | 接入 | 通过兼容的 HTTP 服务返回结果或任务 ID；不是本地生成模型，也不是全部服务商专用适配 |
| 无密钥本地指令 | 基础 | 确定性命令解析，按全部注册节点的中文名、英文名或类型 ID 添加节点，优先匹配完整长名称；仍是有限图操作，不是离线大语言模型 |
| 大模型对话改图 | 接入 | 模型返回受白名单约束的图修改建议，预览并应用；不执行任意模型代码 |
| 长任务轮询与取消 | 计划 | 服务商返回异步任务 ID 时，尚无统一后台轮询与持久队列 |
| 流式生成与进度 | 计划 | 尚无覆盖所有模态和服务商的流式进度协议 |
| 生成媒体持久化 | 基础 | 返回的 base64 媒体落盘；远端 URL 仍是引用，尚无所有远端资产的自动归档 |
| 生成成本与额度 | 计划 | 无统一计费估算、消费上限和账户余额同步 |
| 所有厂商与模型通用兼容 | 计划 | HTTP 模板降低接入成本，不保证任何 API 填入地址后即可工作 |

所有远程 AI 能力都需要使用者自己的服务地址、模型、账号和权限。开发验证可使用本地模拟服务；没有真实服务商凭据时，不能把模拟接口测试写成真实生成成功，也不会把占位图当作生成结果。

## MCP 接入

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| TD Open 作为 MCP 服务端 | 接入 | 官方 Python SDK 的 stdio server，将项目操作暴露为工具；需要运行应用 HTTP 服务 |
| TD Open 连接远端 MCP | 接入 | Streamable HTTP 客户端，初始化会话、列举工具、调用工具 |
| 远端认证 | 接入 | 可配置 Bearer token；尚无完整 OAuth 授权流程 |
| 工具允许列表 | 基础 | 支持配置工具名限制；对话不会自动调用任意外部工具 |
| 通过 MCP 改图 | 基础 | 工具调用进入校验后的项目命令路径；支持的操作以工具 schema 为准 |
| 完整 MCP 能力集 | 计划 | 不声称完整支持 resources、prompts、sampling、elicitation、订阅或所有协议版本 |
| 持久远端会话与恢复 | 计划 | 当前按请求建立客户端会话；无跨调用长期会话管理与恢复保证 |
| MCP 最新版本兼容 | 计划 | 使用 SDK 支持的协议协商；没有对所有新规范进行认证或完整合规测试 |

MCP 的标准 transport 包括 stdio 与 Streamable HTTP；本项目区分服务端和客户端方向。协议定义见 [MCP transports](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)，实现依赖和支持范围还应核对安装版本的 [Python SDK 文档](https://py.sdk.modelcontextprotocol.io/v1/)。

## 设备、输出、性能与分发

| 功能域 | 状态 | 当前范围与边界 |
| --- | --- | --- |
| OSC / MIDI / 串口 | 计划 | 尚无设备发现、端口配置、映射与重连实现 |
| DMX / Art-Net / sACN | 计划 | 尚无灯光设备协议和 universe 管理 |

| VR / XR 与专用输出 | 计划 | 无原生头显、激光器或 LED 屏控制链路 |
| 投影 mapping | 计划 | 无投影曲面、控制点、边缘融合、相机标定和多投影机工作流 |

| 可预测的实时性能 | 计划 | 未对全部图规模、分辨率和硬件建立实时性能保证 |
| 逐节点 profiler 与缓存 | 计划 | 无完整 cook scheduler、依赖缓存和 GPU 内存预算系统 |
| 本地运行 | 基础 | 浏览器界面加本机 Python 服务；默认本地地址使用端口 8765 |
| 原生桌面安装包 | 计划 | 无 Windows/macOS/Linux 已签名安装包或内置原生桥接 |
| 公网生产部署 | 计划 | 当前服务为本地开发工具；账户、细粒度权限、租户隔离和部署运维仍需建设 |
| `.toe` / `.tox` 读写 | 计划 | 不读取、不写入、不执行这些格式，也不承诺兼容 |

## 对照依据

Derivative 当前 [Operator Family](https://derivative.ca/UserGuide/Operator_Family) 将功能组织为 TOP、CHOP、POP、SOP、DAT、MAT 与 COMP 七个族；其中 COMP 具有层级容器语义。TD Open 仅借用这些领域术语帮助理解自身数据类型。

以下官方资料用于确定缺口，不代表导入了其中的代码、图形或资源：

- [CHOP](https://derivative.ca/UserGuide/CHOP)：采样通道、音频与控制信号的范围。
- [Learning About POPs](https://derivative.ca/UserGuide/Learning_About_POPs)：GPU 几何与属性模型。
- [Projection Mapping](https://derivative.ca/UserGuide/Projection_Mapping)：映射、校正和投影相关工作流。
- [NDI In TOP](https://derivative.ca/UserGuide/NDI_In_TOP)：网络视频功能参照。
- [System Requirements](https://docs.derivative.ca/System_Requirements)：原软件功能存在平台、驱动与硬件差异，不能用浏览器演示替代逐项验证。

TD Open 与 Derivative 无隶属关系。TouchDesigner 的名称和商标归其权利人所有；本项目的 MIT 许可适用于自行编写的代码，第三方依赖与素材遵循各自许可。
