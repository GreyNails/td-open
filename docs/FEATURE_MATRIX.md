# 功能矩阵与兼容边界

更新：2026-10-14，0.5 Alpha。本次按用户提供的六张节点目录截图逐项对照。节点同名不表示 TouchDesigner 的参数、结果、性能、Python API 或文件格式兼容。

逐项清单见 [reference-capabilities.json](reference-capabilities.json)，每项记录对应节点、实现层级和限制。清单区分实际运行的子集、既有相关实现和需要外部驱动的入口；**外部桥接入口不计为已内置原生功能**。全部节点参数见 [节点手册](NODES.md)，实测范围见 [验证记录](VALIDATION.md)。

## 参考截图没有覆盖的系统能力

六张截图是节点目录，不是完整软件规范。`.toe/.tox` 兼容、POP GPU 属性网络、完整参数表达式/导出/绑定、商业编解码器、离线音画渲染、专业色彩管理、跨机器同步和长时间演出稳定性仍未补齐。不能用目录映射数替代这些能力的完成度。

默认输出为 640 × 360；Resolution 等节点能调整自身结果，后续旧节点仍按默认画幅处理。CPU 像素与网格算法、软件 WebGL 环境和设备本身都会影响帧率，尚不承诺 4K/60fps。项目图预算是 5,000 节点 / 20,000 连接，嵌套复制展开同样受限制。

这是独立实现的创作工具，与 Derivative 无隶属关系，不含其程序或源码。参考材料不会随公开源代码分发。
